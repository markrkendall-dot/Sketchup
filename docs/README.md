# Docs

- **[DESIGN.md](DESIGN.md)**: how HomePlan works inside: the data model, units, the wall graph, corner
  joins, rooms, roofs, terrain, 3D meshes, export, and the editing tools. Read it before changing
  `src/model`, `src/derive` or `src/editor2d`.
- **[examples/146-mick-road.json](examples/146-mick-road.json)**: the starter plan of the owner's house,
  generated by `npm run build:example` from `scripts/example-plan.ts`. The README section "Modelling
  146 Mick Road" explains every number in it.
- **[photos/](photos/)**: the reference photos of the house (01 to 09), the site sketch (10), the
  owner's first- and second-floor measurement sketches (11, 12), and the first floor as it is today,
  room by room, with the lake side from below (13 to 23). File names give the face or the room and
  the direction the camera faces; the starter plan was built from these.
- **[history/](history/)**: planning and review records, kept for the reasoning behind decisions.
  - `PLAN-v2.md`: the plan for roofs, terrain, finishes and the starter house.
  - `PLAN-v3-realism.md`: the plan for making the exterior and the elevations read like the photos
    (light and shadows, siding and roof textures, sashes and screens, open eaves, the chimney's cap,
    elevation views, and the starter's windows, roofs and finishes re-estimated from the photos).
  - `PLAN-v4-proposed.md`: the plan for drawing the owner's proposed design into the starter as new
    and demolished work (master suite, kitchen, stair and front door, powder room, foyer and screen
    porch), with the flight and room-label fields it needed, and where the built design differs.
  - `PLAN-v5-kitchen.md`: the plan for the proposed kitchen in the starter (the island with the sink
    and dishwasher facing the lake, two stools, the refrigerator between pantries, the range wall
    and counter in the old bath's alcove, the closet and the moved bedroom door), and where the
    built kitchen differs.
  - `PLAN-v6-layout.md`: the plan for the stair hall open through both floors, the north band
    (powder room and pantry), the wood stove, the laundry and the upstairs bath.
  - `PLAN-v7-exterior-flue.md`: the stove's flue routed outside the house, with the 2025
    Residential Code of New York State checklist it was laid out to.
  - `PLAN-v8-stair-structure.md`: the plan for the grand staircase in detail, the NY stair checks,
    walk mode on stairs, renovation wall moves, and beams, posts, footings and load-path checks.
  - `QA-FINDINGS.md`: the first hands-on QA pass and the second review's status.
  - `REVIEW-2.md`: the second review of the house and the tools, with the fixes made.
