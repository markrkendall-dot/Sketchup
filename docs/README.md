# Docs

- **[DESIGN.md](DESIGN.md)**: how HomePlan works inside: the data model, units, the wall graph, corner
  joins, rooms, roofs, terrain, 3D meshes, export, and the editing tools. Read it before changing
  `src/model`, `src/derive` or `src/editor2d`.
- **[examples/146-mick-road.json](examples/146-mick-road.json)**: the starter plan of the owner's house,
  generated by `npm run build:example` from `scripts/example-plan.ts`. The README section "Modelling
  146 Mick Road" explains every number in it.
- **[photos/](photos/)**: the reference photos of the house (01 to 09), the site sketch (10), and the
  owner's first- and second-floor measurement sketches (11, 12). File names give the face shown; the
  starter plan was built from these.
- **[history/](history/)**: planning and review records, kept for the reasoning behind decisions.
  - `PLAN-v2.md`: the plan for roofs, terrain, finishes and the starter house.
  - `QA-FINDINGS.md`: the first hands-on QA pass and the second review's status.
  - `REVIEW-2.md`: the second review of the house and the tools, with the fixes made.
